# Car Sales Data Analysis

## Project Overview
This project focuses on analyzing car sales data to uncover insights related to manufacturer performance, pricing trends, vehicle types, and sales patterns over time.

The analysis was performed using Python for data cleaning and exploratory analysis, and Excel for creating an interactive dashboard.

---

## Tools & Technologies
- Python (Pandas, Matplotlib)
- Microsoft Excel (Pivot Tables, Charts, Slicers)
- Jupyter Notebook

---

## Key Analysis Steps
- Cleaned and preprocessed the dataset
- Handled missing values and removed irrelevant columns
- Performed exploratory data analysis (EDA)
- Aggregated sales and pricing metrics
- Built an interactive Excel dashboard

---

## Key Insights
- Ford leads total sales among manufacturers
- Passenger vehicles dominate overall sales
- Luxury brands have higher average prices but lower sales volume
- Sales increased significantly in recent launch years

## How to Use
1. Review the Jupyter notebook for analysis
2. Open the Excel file to explore the interactive dashboard
3. Use slicers to filter by vehicle type and launch year
